DESAFIO 60 — versão web/PWA

Para testar: abra index.html no navegador de um computador.
Para instalar como PWA no iPhone: hospede estes arquivos em HTTPS; abra o endereço no Safari; Compartilhar > Adicionar à Tela de Início.
O service worker só é ativado quando servido por HTTP(S), e o uso offline depende de instalação/cache prévio.
Esta versão não tem login, ranking online ou pagamentos.
